Интерфейс для проверки
Демонстрационный макет. Курсы и тарифы — пример, формулы требуют согласования. При запуске через start_windows.bat версии расчётов сохраняются в SQLite. Прямое открытие HTML работает без базы.

Инвойс в расчётной валюте

Сохранённые версии расчётов

Каждое сохранение создаёт отдельную запись. После открытия расчёта изменения сохраняются новой версией; исходный расчёт остаётся в истории. Ставки и курсы обновляются вручную.
